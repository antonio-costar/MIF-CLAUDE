# Coding Preferences

## Core Principles

- Prefer clarity over cleverness.
- Optimize for readability and maintainability.
- Avoid unnecessary abstractions.

## Variable Naming

- Use descriptive variable names.
- Avoid single-letter variables except in very small, obvious scopes.
- Name variables based on business meaning rather than technical implementation.

Good:
- income_rate
- missing_percentage
- target_distribution

Avoid:
- x
- tmp
- data2
- result_final_v2

## Comments

- Write Functional comments 
- Avoid Technical comments

## Code Organization

- Break complex logic into clearly named steps.
- Reuse existing utility functions whenever possible.
